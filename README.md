# 绣花打版仿真系统

纯前端绣花打版软件：在浏览器里完成打版、配色、仿真预览和 DST 导出，上机前先把效果看准。
所有数据存在浏览器本地（localStorage），刷新不丢，可打包发给别人。

## 运行

无需安装任何东西，任选其一：

```bash
# 方式一：本地起个静态服务（推荐）
python -m http.server 8764
# 然后浏览器打开 http://localhost:8764

# 方式二：直接双击 index.html（针迹计算用了 Blob Worker，file:// 也能跑）
```

## 页面

| 页面 | 功能 |
|------|------|
| 工程列表 | 新建/复制/删除工程，自动保存，缩略图预览，打包导出/导入（.embpkg.json），导入 SVG / DST |
| 打版编辑 | 画矩形/椭圆/多边形/包针线/平针线；控制点拖拽改形、框选移动、网格吸附、撤销重做（Ctrl+Z/Y）、双击边线加点、右键删点 |
| 配线配色 | 绣作顺序排序、Madeira 色板换色、插入剪线、空跳剪线阈值和转速设置 |
| 仿真预览 | 按真实线径逐针绘制，放大看针脚；布料底色、绷子规格可换；侧视角度+丝线光泽；走针动画 |
| 统计导出 | 针数/用线/换色/工时统计，导出 DST、工单 CSV、工程包，DST 再导回继续改 |

## 针法

- **平针**：沿折线等距走针，针距可调
- **榻榻米**：扫描行填充，行距（密度）、针距、角度、错针模式、收缩补偿、轮廓底线
- **锯齿针**：行内上下交替，行距针距可调
- **包针**：沿骨架中心线按各点宽度向两侧出针，宽窄变化自动收口，带中心平针+锯齿双层底线和收缩补偿

## 关键设计

- 针迹计算全部在 Web Worker 里跑（`js/worker-code.js`），10 万针重算约 10ms，界面不卡
- 同色块内图形按最近邻排序（最短路径），闭合轮廓起点自动对齐到最近点；空跳超过阈值自动插剪线
- DST 按 Tajima 标准编码：普通针 0x03、跳针 0x83、换色 0xC3、剪线为原地跳针，可无损导回
- SVG 导入：填充区域→榻榻米（evenodd 自动认孔），粗描边→包针，细描边→平针，颜色就近匹配 Madeira 线号；文件损坏给出明确提示，不白屏

## 文件结构

```

css/style.css       样式
js/util.js          几何与工具
js/threads.js       Madeira 色卡（近似色值）
js/samples.js       内置花稿（花朵/星星/爱心）
js/worker-code.js   针迹计算 Worker（平针/榻榻米/锯齿/包针、排序、剪线）

js/svg.js           SVG 导入

js/app.js           路由、状态、Worker 调度、自动保存
js/page-*.js        五个页面
```
