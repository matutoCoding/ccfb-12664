# 浏览器端绣花打版与仿真系统

纯前端、零后端、离线可用的电脑绣花打版工具。所有工程数据保存在浏览器本地（IndexedDB，localStorage 降级），刷新不丢；针迹计算在 Web Worker 中运行，十万针级花样重算在百毫秒内，界面缩放拖动不卡顿。

## 启动

```bash
npm start          # 然后浏览器访问 http://localhost:8080
```

> 必须通过 HTTP 服务访问（ES Module + Web Worker 限制），不要直接双击 index.html 用 file:// 打开。
> 若 Worker 因特殊环境无法创建，系统自动降级到主线程计算，功能不受影响。

## 测试

```bash
npm test           # Node 核心算法冒烟测试（111 项，无需浏览器）
node test/e2e.mjs  # Playwright 浏览器端到端测试（需安装 playwright 包）
```

## 核心能力对照需求

1. **工程管理**：新建/复制/删除，自动保存（防抖 600ms），刷新不丢，`.embz` 压缩包可发给他人导入。
2. **内置花稿 + SVG 识别**：4 个内置花稿；SVG 支持 path/rect/circle/ellipse/polygon/line 与贝塞尔、圆弧、transform，自动展平轮廓出针迹；坏文件弹中文错误，绝不白屏。
3. **四种针法**：平针、包针（榻榻米柱）、榻榻米、锯齿针；密度、针距、长短针可调，改参数即重算。
4. **包针收口**：沿 PCA 主轴切片生成骨架横档，宽度随轮廓自然收缩；带底线（中心线 + 横向固定）与收缩补偿（多边形外扩）。
5. **配线**：按绣作顺序排列，可换色、上下排序；剪线/跳针自动插入；内置 26 色 Madeira Rayon 线号色板，可自定义增删。
6. **仿真**：按真实线径一针一针绘制，阴影 + 主线 + 高光三层表现线的凸起与光泽；布料底色、绷子型号可换；侧倾观察时光泽增强；放大可见针脚。
7. **统计**：针数、用线长度、换色/剪线/跳针次数、预估工时（含换色剪线辅助时间），参数改动实时刷新。
8. **编辑交互**：控制点拖拽改形、Ctrl+Z/Y 撤销重做（50 步）、Shift 框选移动、网格吸附对齐。
9. **DST 导出**：标准 512 字节头 + 三进制三字节针迹记录，跳针 0x80、换色 0x83、结束 0xF3，超量程自动拆分；DST 可导回为原始针迹块继续编辑；工单另存 UTF-8 BOM 的 CSV。
10. **性能**：实测 15.7 万针重算约 57ms（要求 <1s）；计算全部在 Worker，主线程仅负责渲染。

### 最在意的三条工艺规则

- **针迹不交叉乱穿**：榻榻米蛇形扫描（相邻行反向、边缘连接）；包针横档左右交替、连接沿边缘走；同色块用最近邻贪心 + 2-opt 优化连接顺序，消除空跳交叉。
- **同色块最短路径**：每色内部按最近邻排序并支持整块翻转（选近的一端进入），再做 2-opt 去交叉。
- **超阈值空跳插剪线**：空跳距离超过设定阈值（默认 7mm，可调 2–20mm）自动插剪线码；超长空跳拆分为多条跳针记录。

## 目录结构

```
core/         纯计算层（无 DOM，可在 Worker/Node 运行）
  constants.js  单位、默认参数、标志位
  math.js       2D 几何、折线、多边形、最近邻/2-opt
  geometry.js   主轴切片、扫描线填充、骨架横档
  svg-parser.js SVG 展平解析
  engine.js     四种针法生成 + 全局路由 + 统计
  dst.js        DST 三进制编码/解码（穷举往返验证）
  zip.js        纯 JS ZIP 打包/解包
  csv.js        工单 CSV
  store.js      IndexedDB 存储、历史快照、工程包
  stitch-worker.js / worker-client.js
canvas/       画布视口、编辑器交互、仿真渲染、缩略图
data/         Madeira 色板、布料绷子、内置花稿
ui/pages/     五个页面
test/         Node 冒烟测试 + Playwright E2E
```

## 数据与隐私

全部数据仅存于本机浏览器，不上传任何服务器。清除浏览器站点数据会删除工程，重要花样请及时用 `.embz` 打包备份。
